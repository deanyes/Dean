# 🌤️ 极致天气应用 | Ultimate Weather App

一个具有极致设计风格和酷炫交互动效的现代化网页版天气应用。

## ✨ 特性

### 🎨 设计亮点
- **玻璃态设计（Glassmorphism）** - 半透明磨砂玻璃效果
- **动态渐变背景** - 流动的渐变色彩动画
- **粒子背景效果** - 漂浮的粒子装饰
- **流畅动画过渡** - 所有交互都有精心设计的动画
- **响应式设计** - 完美适配所有设备尺寸

### 🚀 交互功能
- **城市搜索** - 搜索全球任意城市的天气
- **地理定位** - 一键获取当前位置天气
- **实时更新** - 自动更新日期时间
- **详细信息** - 温度、湿度、风速、气压等完整数据
- **24小时预报** - 每小时天气变化趋势
- **7天预报** - 未来一周天气预测

### 🎭 动效体验
- ⚡ 悬浮卡片效果
- ⚡ 平滑加载动画
- ⚡ 动态天气图标
- ⚡ 交互式元素反馈
- ⚡ 错误提示动画
- ⚡ 列表渐进展示

## 🛠️ 技术栈

- **纯原生技术** - 无框架依赖
  - HTML5
  - CSS3 (动画、渐变、玻璃态)

- **天气数据** - OpenWeatherMap API

## 📦 快速开始

### 1. 克隆项目
```bash
git clone <repository-url>
cd Dean
```

### 2. 获取 API 密钥
1. 访问 [OpenWeatherMap](https://openweathermap.org/api)
2. 注册免费账号
3. 获取 API 密钥

### 3. 配置 API 密钥
打开 `script.js` 文件，找到第 5 行：
```javascript
this.apiKey = 'YOUR_API_KEY_HERE';
```
将 `YOUR_API_KEY_HERE` 替换为你的实际 API 密钥。

### 4. 运行应用
直接在浏览器中打开 `index.html` 文件，或使用本地服务器：

**使用 Python 3:**
```bash
python -m http.server 8000
```

**使用 Node.js (http-server):**
```bash
npx http-server
```

**使用 VS Code Live Server:**
右键点击 `index.html` -> "Open with Live Server"

然后在浏览器中访问 `http://localhost:8000`

## 🎯 使用方法

### 搜索城市
1. 在搜索框中输入城市名称（支持中文和英文）
2. 点击搜索按钮或按 Enter 键
3. 查看该城市的完整天气信息

### 使用定位
1. 点击定位按钮（GPS 图标）
2. 允许浏览器访问你的位置
3. 自动显示当前位置的天气

### 查看预报
- **24小时预报** - 横向滚动查看每小时天气
- **7天预报** - 查看未来一周的天气趋势
- **详细信息** - 点击卡片查看更多细节

## 🔧 自定义

### 更改主题颜色
在 `style.css` 中修改 CSS 变量：
```css
:root {
    --primary-color: #667eea;
    --secondary-color: #764ba2;
    --accent-color: #f093fb;
}
```

### 调整粒子数量
在 `script.js` 中修改粒子数量：
```javascript
createParticles() {
    const particleCount = 50; // 修改这个数值
    ...
}
```

### 修改动画速度
在 `style.css` 中调整动画持续时间：
```css
animation: gradientShift 15s ease infinite; /* 调整秒数 */
```
